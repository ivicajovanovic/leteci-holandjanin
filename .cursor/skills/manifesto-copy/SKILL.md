# Manifesto copy

Read `/design/voice.md` and fill `/design/templates/copy-context.md` first.

## Rules

- Declarative statements of what the thing does. Not a pitch deck.
- Specific over vague. Honest over sensational. Clarity over cleverness.
- Verbs for actions, nouns for destinations.
- Errors: problem + recovery.
- Confirmations state consequence, not “Are you sure?”.
- Sequence: orientation → claim → proof → action → detail.

## Do not write

Supercharge, all-in-one, unleash, seamless, powerful, next-generation, Learn more, Continue, Submit (when a precise verb exists), fake Trusted-by, invented percentages, false urgency, slang, emoji-as-icon.

If a number is not sourced, omit it or label `SAMPLE DATA`.
