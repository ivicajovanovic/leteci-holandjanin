# This is not

Do not imitate these. The fence (`npm run fence`) fails the implementation if they appear in `src/` or `public/`.

| Pattern | Why it fails this project |
|---|---|
| Inter, Roboto, Open Sans, Source Serif, Playfair, Fraunces | Dutch pairing only, after lock |
| Cream canvas `#F2F0EA` / `#FAFAF7` | Gen-AI *reference* theme, not our values |
| `rounded-xl`, pills, `rounded-full` | `rounded-none` |
| Three equal feature cards, bento soup | Unequal index / `<dl>` / rules |
| Centered hero stack | Content on a grid line; one bleed |
| `hover:scale-105`, fade-in-up | Inversion or chevron-axis spring |
| Purple glow, sparkles, orb, chatbot shell | AI is behavior, not chroma |
| Soft `box-shadow` | 1px rules or hard offset, 0 blur |
| Two accent hues in CSS | One accent, others deleted |
| Invented `%` / live status | Source it or label `SAMPLE DATA` |

The positive fragment is `this-is.html` and `this-is.png`. Copy structure, not decoration.
