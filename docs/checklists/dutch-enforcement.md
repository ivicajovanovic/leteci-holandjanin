# Dutch enforcement

Mirror of `design/sources/anti-slop-dutch-design.md` enforcement. If any box is unchecked, the work is not finished.

- [ ] `design-plan.md` names family, inversion pair, emphasis chromas, packing grid, angle lock, field inversion map, generating rule, type math, motion, states, data honesty
- [ ] No serif. No Fontshare fashion pair. No alien logotype family
- [ ] Fields are near-black / off-white inversion, not `#000`/`#FFF`. ≤2 emphasis chromas from soft red / kiwi / dark yellow / orange / grass green
- [ ] Packing grid real and invisible by default. No drawn column overlay unless named as a print mark
- [ ] Type at 0° / 90°. Switcher arrows from `public/arrows/`. No CSS 45°. No 3° / −4°
- [ ] Expressive pages invert adjacent major sections; 90° type rides those fields. Quiet stays on one field
- [ ] At least one word- or sentence-as-object per page, on an inverted field, same family as body
- [ ] Generating rule applied. Chevrons are not a per-section quota
- [ ] Raster/photo, if used, shows print grain / silkscreen / overprint
- [ ] Numbered indexes are not card-grid twins
- [ ] Every number traced to a source or `SAMPLE DATA`
- [ ] No glitch text-shadow
- [ ] No ribbon badges or emoji-as-icon
- [ ] No unplanned dead column gaps
- [ ] Gray only for print marks and muted secondary text
- [ ] No row from the Forbidden columns
- [ ] `:focus-visible` in a locked chroma
- [ ] No-Cripple-MVP
- [ ] Motion signature consistent; no spring theater on Jetset-led print compositions
