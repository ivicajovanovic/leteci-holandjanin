# Language

Three layers. Do not mix them.

| Layer | Language | Files |
|---|---|---|
| Law and agents | English | `design/sources/*`, `AGENTS.md`, `.cursor/`, `design/*.md` except README notes, code comments |
| Owner README | Serbian, ekavian | `README.md` only |
| Product UI | One locale, locked in `design-plan.md` | Pages, content collections, visible copy |

Do not translate the two source law files. Do not use ijekavian or ikavian in Serbian product copy. Until `design-plan.md` is `LOCKED`, do not assume the site is `hr`, `sr`, or `en`.
