# Intensity modes

From Generation AI kit §6, mapped onto Dutch grid + rupture. One product may change mode by journey stage. Forms, auth, payment, privacy, and destructive actions stay `quiet` even on an expressive page.

| Mode | Where | Visual | Motion |
|---|---|---|---|
| `expressive` | Brand, editorial, discovery, portfolio | Packing felt, not drawn. Adjacent sections invert (off-white ↔ near-black). 90° type on those fields. Generating rule fires. | Dutch spring / overshoot on Dumbar/DEPT surfaces. |
| `immersive` | Campaign, culture, media | Richer media. Navigation and controls stay stable. Full-bleed may interrupt rhythm, not task continuity. | Scene motion up to 600ms, still overshoot, still interruptible. |
| `quiet` | Checkout, settings, permissions, errors | No rupture theater. One field only (typically off-white / near-black). Square controls. Invisible packing. One dominant action. | Instant or snap inversion for state. Spring only for feedback. |

Set `data-intensity` on `<body>` or the section root. CSS and components read that attribute. Do not mix two global CTAs in one context.
