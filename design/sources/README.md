# Design sources (law)

These two files are the project’s design law. Do not replace them with a third aesthetic.

| File | Role |
|---|---|
| [`anti-slop-dutch-design.md`](./anti-slop-dutch-design.md) | Visual and compositional law for anything rendered in a browser (HTML, CSS, Astro, JSX). Dutch Design: Experimental Jetset × Studio Dumbar. |
| [`gen-ai-web-design-style-kit.md`](./gen-ai-web-design-style-kit.md) | Behavioral, ethical, accessibility, performance, and AI-interaction law. Design language: Controlled Intensity. |

When they disagree, follow [`../CONFLICTS.md`](../CONFLICTS.md). Visual form follows Dutch Design. Interaction ethics, WCAG version, Core Web Vitals, provenance, and intensity modes follow the Generation AI kit.

Do not invent a second visual direction. Do not treat the Generation AI reference fonts or cream canvas as brand identity.
